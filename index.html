Défuse
la mallette

Un désamorceur voit la mallette. Un expert lit le manuel. Parlez-vous vite.

Mode

Manuel

Réglages

Score = 5 000 + 10 × secondes restantes − 500 × erreurs − 250 × indices.

Comment jouer

  1. Le désamorceur tient la mallette (ce téléphone). Il décrit ce qu’il voit : couleurs des fils, du clavier, des DEL, le code de partie.
  2. L’expert ouvre le manuel sur un autre appareil (code QR au départ). Il ne voit pas la mallette et dit quoi faire.
  3. Mode Équipe : tout le monde voit la mallette et le manuel (bouton 📖) sur le même appareil.
  4. Touchez un module pour vous en approcher. Glissez à gauche ou à droite, ou ◀ ▶, pour changer de module.
  5. Fils : touchez un fil pour le couper. Clavier : touchez les touches. Joystick : glissez le manche, touchez-le pour cliquer. Badges : touchez un badge pour le passer sur le lecteur. Inclinaison : penchez le téléphone (📱) ou glissez sur le module, et « Secouer ».
  6. 💡 Indice : 1er appui = la ligne du manuel, 2e appui = la prochaine action. Chaque indice coûte 250 points.
  7. Clavier d’ordinateur : Tab / Maj+Tab change de module, Échap = vue d’ensemble, H = indice, M = son ; chiffres, A–D, * et # pour le clavier ; flèches + Entrée pour le joystick ; flèches + S pour l’inclinaison.
